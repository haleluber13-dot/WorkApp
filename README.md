# יומן הפקה

אפליקציית אייפון לניהול יום צילום — בנויה אחד לאחד לפי גיליון האקסל של ההפקה,
עם כל מה שהגיליון לא יודע לעשות: להתקשר, לנווט, ולדעת מי מגיע ומתי.

הכול בעברית, מימין לשמאל.

---

## מה יש כאן

| תיקייה | מה זה |
|---|---|
| `web/` | **אפליקציית ה־PWA** — עובדת על האייפון היום, בלי מק ובלי App Store |
| `ios/` | **פרויקט SwiftUI נייטיב** — אפליקציה אמיתית, דורשת מק עם Xcode |
| `supabase/` | סכימת מסד הנתונים לסנכרון בין אנשי הצוות |

שתי האפליקציות מדברות לאותו מסד נתונים, כך שאפשר להתחיל עם ה־PWA ולעבור
לנייטיב בלי לאבד נתונים.

---

## הגיליון שהפך לאפליקציה

חמשת הגיליונות מהאקסל קיימים באפליקציה, עם אותם שמות ואותו סדר עמודות:

| גיליון | עמודות |
|---|---|
| **הפקה** | ע הפקה ג ×2, ע הפקה ×2, נערת מים, צלם 1/2/3, ע צלם ×2, מקליט, בום, תאורן, ע תאורן, גריפ |
| **קיטריינג** | צוות, שחקנים, ניצבים/ביטים, הוזמן בוקר, הוזמן צהריים, אכלו בוקר, אכלו צהריים |
| **רכבים** | משאית, ארט, הפקה־מצלמה, תאורה גריפ, מחנה, הפקה, פרופס, סקאוטר |
| **ניקיון** | מנקה ×2 |
| **שמירה** | שומר ×2 |

> גיליון **שמירה** היה ריק לגמרי בקובץ המקורי. הוספתי לו שתי עמדות שומר לפי
> המבנה של גיליון הניקיון. אם המבנה האמיתי שונה — זה שינוי של שורה אחת
> בקובץ `web/js/model.js` (וב־`ios/WorkApp/Models/Model.swift`).

בכל גיליון יש שתי תצוגות:

* **היום** — כל עמודה היא שורה שאפשר ללחוץ עליה כדי לשבץ איש צוות.
* **טבלה מלאה** — הטבלה המוכרת, כל ימי הצילום, בסדר העמודות המקורי.

---

## מה האפליקציה עושה מעבר לגיליון

* **סרגל אנשי קשר** — כל מי שמשובץ ליום, בשורה אחת בראש המסך. לחיצה פותחת
  חיוג, וואטסאפ, ניווט ושינוי שעת קריאה.
* **מיקומים** — לוקיישן שמור עם כתובת, חניה וקואורדינטות. כפתור ניווט אחד
  פותח ווייז (או מפות אפל / גוגל, לפי הבחירה בהגדרות).
* **שעות** — קריאה כללית, תחילת צילום וסיום ליום, ושעת קריאה אישית לכל אדם.
  המסך מדגיש את היעד הקרוב ומראה כמה זמן נשאר.
* **סטטוס הגעה** — ממתין / אושר / בסט / לא מגיע, עם נקודה צבעונית ליד כל אחד.
* **הודעת קריאה מוכנה** — טקסט מלא עם תאריך, שעה, לוקיישן וחניה, נשלח
  בוואטסאפ בלחיצה.
* **עובד בלי קליטה** — כל הנתונים על המכשיר. הסנכרון הוא תוספת, לא תנאי.

## איך מתחילים — האפליקציה בטלפון

1. ב־GitHub: **Settings → Pages → Source → GitHub Actions**.
2. ה־workflow רץ אוטומטית בכל דחיפה. הכתובת תופיע בטאב **Actions** בסיום,
   והיא בצורת `https://<שם המשתמש>.github.io/WorkApp/`.
   *אם שלב ה־deploy נכשל:* סביבת `github-pages` מגבילה ברירת מחדל לענף
   הראשי. או שממזגים ל־`main`, או שמאשרים את הענף תחת
   **Settings → Environments → github-pages → Deployment branches**.
3. פותחים את הכתובת **בספארי באייפון** (לא בכרום).
4. כפתור השיתוף ← **הוספה למסך הבית**.
5. זהו. אייקון משלה, מסך מלא, עובדת אופליין, וחיוג וניווט עובדים.

### רוצים רק להתרשם?

בפתיחה הראשונה יש כפתור **״מילוי נתוני דוגמה״** — הפקה שלמה עם צוות, שעות,
רכבים וקיטריינג, כדי לראות איך הכול נראה לפני שמזינים משהו. אפשר לטעון אותה
שוב או למחוק הכול מ**הגדרות ← נתונים**.

> אם פותחים את האפליקציה כתצוגה מוטמעת בתוך דף אחר, המערכת חוסמת מעבר
> לחייגן. במצב הזה לחיצה על חיוג **מעתיקה את המספר** במקום להתקשר, וגיבוי
> מועתק ללוח במקום לרדת כקובץ. בגרסה המותקנת במסך הבית הכול עובד רגיל.

אפשר גם להריץ מקומית לבדיקה:

```bash
cd web && python3 -m http.server 8080
# ואז http://localhost:8080 בדפדפן
```

### הצעדים הראשונים באפליקציה

1. **אנשי קשר** ← מוסיפים את הצוות פעם אחת (שם, טלפון, מחלקה, תפקיד קבוע).
2. **הגדרות** ← מוסיפים לוקיישן אחד לפחות.
3. **ימים** ← יוצרים יום צילום: תאריך, לוקיישן, שעת קריאה כללית.
4. **גיליונות** ← משבצים את הצוות בעמודות.

מי שמוגדר לו "תפקיד קבוע" יקפוץ לראש הרשימה כשמשבצים לאותה עמודה — אחרי
היום הראשון השיבוץ הופך למספר לחיצות.

## סנכרון עם הצוות

בלי סנכרון האפליקציה עובדת במלואה, רק על המכשיר שלכם. כדי לשתף:

1. פותחים פרויקט חינמי ב־[supabase.com](https://supabase.com).
2. ב־**SQL Editor** מריצים את `supabase/schema.sql`.
3. ב־**Settings → API** מעתיקים את ה־`Project URL` ואת מפתח ה־`anon public`.
4. באפליקציה: **הגדרות ← סנכרון צוות**, מדביקים, **בדיקת חיבור**, **הפעלה**.
5. כל מי שמזין את אותם פרטים רואה את אותם נתונים.

**"מזהה פרויקט"** מפריד בין הפקות שונות על אותו שרת — הפקה אחת `drama-s2`,
אחרת `commercial-nov`, בלי להתערבב.

> ⚠️ **על האבטחה:** בהגדרה הבסיסית, כל מי שמחזיק במפתח יכול לקרוא ולכתוב את
> כל ההפקה — שמות, טלפונים ולוקיישנים. אל תפרסמו את המפתח בפומבי. בסוף
> `supabase/schema.sql` יש הסבר איך להדק את זה עם משתמשים מזוהים.

עדכון אחרון מנצח: אם שני אנשים ערכו את אותו יום, הגרסה שנשמרה אחרונה גוברת.
